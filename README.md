# 🎬 HD Video Downloader & Converter (HD Video İndirici ve Dönüştürücü)

A modern, high-performance desktop web application to download videos in 4K, 2K, 1080p Full HD, 60fps and extract high-quality audio (MP3 320kbps, WAV, M4A) from YouTube, Instagram, TikTok, Twitter/X, and 1000+ websites.

---

## ✨ Features / Özellikler

- **Ultra HD & 4K Downloads:** Download videos in 4K (2160p), 2K (1440p), 1080p, and 720p HD with automatic lossless FFmpeg audio/video muxing.
- **Audio Extraction:** Extract crystal-clear MP3 audio at 320 kbps, WAV, or M4A directly.
- **Local Media Converter:** Convert local PC video and audio files (MKV, AVI, WebM, MOV, MP4) with compression and scaling options.
- **Real-Time Progress Tracking:** Live download progress via Server-Sent Events (SSE) showing percentage, speed (MB/s), ETA, and file size.
- **Batch Download:** Queue and download multiple links at once.
- **Zero Heavy Dependencies:** Built on top of Deno TypeScript backend, native browser frontend, `yt-dlp`, and `FFmpeg`.

---

## 🚀 Quick Start / Başlatma

1. Clone or download this repository.
2. Ensure `yt-dlp` and `ffmpeg` are installed (installed automatically via winget or placed in PATH).
3. Double click `Baslat.bat` to launch the application.
